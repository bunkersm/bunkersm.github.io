    About

    Every day since June 16, 1995, NASA's Astronomy Picture of the Day has featured an image or video of our universe, with a short explanation written by a professional astronomer. This site uses the free NASA Open APIs to browse the archive.

    The shared demo key is rate-limited. If pictures stop loading, get a free API key and add it under API key in the menu. It is stored only in your browser.

    Images and text courtesy of NASA APOD and the credited authors. Built by Mike Bunkers.
